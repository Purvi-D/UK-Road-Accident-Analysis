# UK Road Accident Analysis using PySpark & Machine Learning

## Project Overview

Road accidents are a significant public safety concern in the United Kingdom. Government authorities and transport agencies rely on accident data to identify high-risk conditions and implement preventive measures.

This project analyses the **UK Road Accident dataset** to uncover patterns and factors contributing to road accidents. Using **PySpark for large-scale data processing** and **machine learning techniques**, the project explores accident trends and key variables influencing accident occurrence.

The goal of the project is to demonstrate how **data analysis and predictive modelling** can help support better road safety decisions.

## Dataset

The project uses the [**UK Road Accident Dataset**](https://www.kaggle.com/datasets/devansodariya/road-accident-united-kingdom-uk-dataset), which contains historical accident records including:

* Date and time of accidents
* Weather conditions
* Road type
* Lighting conditions
* Vehicle and driver related factors
* Accident severity

This dataset is commonly used for **transport safety analysis and predictive modelling**.

## Key Insights

The analysis provided several useful observations from the dataset:

* Accident frequency varies depending on **road type and road conditions**.
* Certain **environmental and weather factors** appear to influence accident occurrence.
* **Time-related patterns** suggest higher accident rates during specific periods of the day.
* Data-driven analysis can help authorities identify **high-risk scenarios and improve road safety strategies**.
